#Java Task 1 - Number Guessing Game

##Description

A simple Java console-based Number Guessing Game developed as part of the OIBSIP internship.
The program generates a random number between 1 and 100. The user has a maximum of 7 attempts to guess the number. After each guess, the program tells the user whether the guess is too high or too low.
The game also supports multiple rounds and keeps track of the player's score.

##Features

-Random number generation between 1 and 100
-Maximum 7 attempts per round
-Too High / Too Low hints
-Correct answer detection
-Score tracking
-Play Again option
-Displays the secret number when the player loses

##Technologies Used

-Java
-Java Random class
-Java Scanner class
-Git & GitHub

##How to Run

Compile the program:

```bash
javac NumberGuessingGame.java
```

Run the program:

```bash
java NumberGuessingGame
```
