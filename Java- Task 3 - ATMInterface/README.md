# ATM Interface System

## About Project

This is a simple ATM Interface System developed using Java.

## Features

* User Login with User ID and PIN
* Check Transaction History
* Withdraw Money
* Deposit Money
* Transfer Money
* Exit the System

## Technologies Used

* Java
* OOP Concepts
* ArrayList
* Scanner

## How to Run

1. Open Command Prompt in the project folder.
2. Compile the Java files:
   `javac *.java`
3. Run the program:
   `java Main`
