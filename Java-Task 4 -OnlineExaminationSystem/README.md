# Java Task 4 - Online Examination System

## About the Project
The Online Examination System is a Java Swing-based application developed as part of my Java Development Internship at Oasis Infobyte (OIBSIP).

## Features
- Student login authentication
- Profile and display name update
- Multiple-choice Java examination
- Next and Previous question navigation
- Countdown timer
- Exam submission confirmation
- Automatic submission when time runs out
- Score and percentage calculation
- Result display
- Logout and exit confirmation

## Technologies Used
- Java
- Java Swing
- Java AWT
- Git and GitHub
